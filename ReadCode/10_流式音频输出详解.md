
# 流式音频输出详解

## 一、概述

流式音频输出是 VibeVoice 的关键特性，允许在语音生成过程中实时播放音频，而不必等待完整生成完成。这大大提升了用户体验，特别是在长文本生成场景。

        AudioPlay["播放音频\n实时输出"]

        Buffer --&gt; AudioPlay
    end
    
    StreamerPut --&gt; Queue

## 二、AudioStreamer 核心实现

在 [`vibevoice/modular/streamer.py`](file:///workspace/vibevoice/modular/streamer.py) 中定义。

### 2.1 初始化

```python
class AudioStreamer(BaseStreamer):
    def __init__(
        self, 
        batch_size: int,                  # 批量大小
        stop_signal: Optional[any] = None, # 结束信号
        timeout: Optional[float] = None,   # 队列超时
    ):
        self.batch_size = batch_size
        self.stop_signal = stop_signal
        self.timeout = timeout
        
        # 为每个样本创建独立队列
        self.audio_queues = [Queue() for _ in range(batch_size)]
        self.finished_flags = [False for _ in range(batch_size)]
        self.sample_indices_map = {}
```

### 2.2 放入音频块

```python
def put(self, audio_chunks: torch.Tensor, sample_indices: torch.Tensor):
    """
    接收音频块并放入对应的队列
    
    Args:
        audio_chunks: 形状 (num_samples, ...) 的音频张量
        sample_indices: 标记这些块属于哪些样本
    """
    for i, sample_idx in enumerate(sample_indices):
        idx = sample_idx.item()
        if idx &lt; self.batch_size and not self.finished_flags[idx]:
            # 转移到 CPU 并放入队列
            audio_chunk = audio_chunks[i].detach().cpu()
            self.audio_queues[idx].put(audio_chunk, timeout=self.timeout)
```

### 2.3 标记生成结束

```python
def end(self, sample_indices: Optional[torch.Tensor] = None):
    """
    标记指定样本或全部样本的生成为结束
    
    Args:
        sample_indices: 可选，要结束的样本索引。None 表示全部结束
    """
    if sample_indices is None:
        # 结束全部样本
        for idx in range(self.batch_size):
            if not self.finished_flags[idx]:
                self.audio_queues[idx].put(self.stop_signal, timeout=self.timeout)
                self.finished_flags[idx] = True
    else:
        # 结束指定样本
        for sample_idx in sample_indices:
            idx = sample_idx.item()
            if idx &lt; self.batch_size and not self.finished_flags[idx]:
                self.audio_queues[idx].put(self.stop_signal, timeout=self.timeout)
                self.finished_flags[idx] = True
```

## 三、迭代器接口

### 3.1 单样本迭代器

```python
class AudioSampleIterator:
    """单个音频流的迭代器"""
    
    def __init__(self, streamer: AudioStreamer, sample_idx: int):
        self.streamer = streamer
        self.sample_idx = sample_idx
        
    def __iter__(self):
        return self
    
    def __next__(self):
        # 阻塞直到有数据
        value = self.streamer.audio_queues[self.sample_idx].get(timeout=self.streamer.timeout)
        if value == self.streamer.stop_signal:
            raise StopIteration()
        return value
```

### 3.2 批量迭代器

```python
class AudioBatchIterator:
    """批量音频流的迭代器"""
    
    def __init__(self, streamer: AudioStreamer):
        self.streamer = streamer
        self.active_samples = set(range(streamer.batch_size))
        
    def __iter__(self):
        return self
    
    def __next__(self):
        if not self.active_samples:
            raise StopIteration()
            
        batch_chunks = {}
        samples_to_remove = set()
        
        # 尝试从所有活跃样本获取块
        for idx in self.active_samples:
            try:
                value = self.streamer.audio_queues[idx].get(block=False)
                if value == self.streamer.stop_signal:
                    samples_to_remove.add(idx)
                else:
                    batch_chunks[idx] = value
            except:
                # 该样本队列为空，跳过本次
                pass
        
        self.active_samples -= samples_to_remove
        
        if batch_chunks:
            return batch_chunks
        elif self.active_samples:
            # 没有准备好的块但还有活跃样本，稍等重试
            import time
            time.sleep(0.01)
            return self.__next__()
        else:
            raise StopIteration()
```

### 3.3 获取流的方法

```python
def get_stream(self, sample_idx: int):
    """获取指定样本的音频流"""
    if sample_idx &gt;= self.batch_size:
        raise ValueError(f"Sample index {sample_idx} exceeds batch size {self.batch_size}")
    return AudioSampleIterator(self, sample_idx)

def __iter__(self):
    """返回批量迭代器"""
    return AudioBatchIterator(self)
```

## 四、异步版本 - AsyncAudioStreamer

对于异步应用场景（如 Web 服务），提供了异步版本。

### 4.1 初始化和队列替换

```python
class AsyncAudioStreamer(AudioStreamer):
    def __init__(
        self, 
        batch_size: int,
        stop_signal: Optional[any] = None,
        timeout: Optional[float] = None,
    ):
        super().__init__(batch_size, stop_signal, timeout)
        # 用 asyncio.Queue 替换普通 Queue
        self.audio_queues = [asyncio.Queue() for _ in range(batch_size)]
        self.loop = asyncio.get_running_loop()
```

### 4.2 线程安全的 Put

```python
def put(self, audio_chunks: torch.Tensor, sample_indices: torch.Tensor):
    """线程安全地放入异步队列"""
    for i, sample_idx in enumerate(sample_indices):
        idx = sample_idx.item()
        if idx &lt; self.batch_size and not self.finished_flags[idx]:
            audio_chunk = audio_chunks[i].detach().cpu()
            # 使用 call_soon_threadsafe 确保线程安全
            self.loop.call_soon_threadsafe(
                self.audio_queues[idx].put_nowait, audio_chunk
            )
```

### 4.3 异步获取流

```python
async def get_stream(self, sample_idx: int):
    """异步迭代器获取流"""
    if sample_idx &gt;= self.batch_size:
        raise ValueError(f"Sample index {sample_idx} exceeds batch size {self.batch_size}")
        
    while True:
        value = await self.audio_queues[sample_idx].get()
        if value == self.stop_signal:
            break
        yield value
```

## 五、在 VibeVoice 推理中的使用

### 5.1 Generate 方法中的集成

```python
@torch.no_grad()
def generate(self, inputs, ..., audio_streamer=None, cfg_scale=1.0, ...):
    # ... 初始化 ...
    
    # 1. 初始化音频块存储
    audio_chunks = [[] for _ in range(batch_size)]
    
    # ... 生成循环 ...
    
    for step in progress_bar:
        # ... 模型前向 ...
        
        # 2. 处理 speech_diffusion token - 核心音频生成
        diffusion_indices = next_tokens == speech_diffusion_id
        if diffusion_indices.numel() &gt; 0:
            # CFG 采样得到隐空间
            speech_latent = self.sample_speech_tokens(...)
            
            # VAE 解码到音频
            scaled_latent = speech_latent / self.speech_scaling_factor - self.speech_bias_factor
            audio_chunk = self.acoustic_tokenizer.decode(
                scaled_latent, 
                cache=acoustic_cache, 
                sample_indices=diffusion_indices
            )
            
            # 存储音频块
            for i, sample_idx in enumerate(diffusion_indices):
                audio_chunks[sample_idx.item()].append(audio_chunk[i])
            
            # 3. 流式输出！
            if audio_streamer is not None:
                audio_streamer.put(audio_chunk, diffusion_indices)
    
    # 4. 结束信号
    if audio_streamer is not None:
        audio_streamer.end()
    
    # ... 拼接完整音频 ...
```

### 5.2 单帧音频的时间特性

- **帧率**：7.5 FPS（每 133ms 一帧）
- **每帧样本数**：3200（24000 Hz / 7.5 = 3200）
- **每帧时长**：3200 / 24000 = 0.133s = 133ms

## 六、完整使用示例

### 6.1 基础示例：同步流式输出

```python
import torch
import numpy as np
from vibevoice.modular.streamer import AudioStreamer

# 1. 初始化 Streamer
batch_size = 1
streamer = AudioStreamer(batch_size=batch_size, stop_signal=None)

# 2. 在另一个线程/进程中生成音频（模拟）
import threading
import time

def generate_audio():
    """模拟音频生成"""
    # 生成 50 帧音频
    for i in range(50):
        # 模拟生成一帧音频（3200样本）
        audio_chunk = torch.randn(3200) * 0.1  # 白噪声
        
        # 放入 streamer
        streamer.put(audio_chunk.unsqueeze(0), torch.tensor([0]))
        
        # 模拟生成耗时
        time.sleep(0.1)
    
    # 结束
    streamer.end()

# 3. 启动生成线程
thread = threading.Thread(target=generate_audio)
thread.start()

# 4. 主线程：消费音频流
print("开始播放流式音频...")
all_audio = []

for audio_chunk in streamer.get_stream(0):
    # audio_chunk 形状 (3200,)
    print(f"收到音频块，形状: {audio_chunk.shape}")
    
    # 可以在这里实时播放！
    # play_audio(audio_chunk.numpy())
    
    all_audio.append(audio_chunk.numpy())

# 5. 拼接完整音频
final_audio = np.concatenate(all_audio)
print(f"生成完成，总时长: {len(final_audio)/24000:.2f}秒")
```

### 6.4 结合真实 VibeVoice 模型

```python
from vibevoice.processor import VibeVoiceProcessor
from vibevoice.modular import VibeVoiceForConditionalGenerationInference
from vibevoice.modular.streamer import AudioStreamer
import threading
import sounddevice as sd

# 1. 加载模型和处理器
processor = VibeVoiceProcessor.from_pretrained("path/to/model")
model = VibeVoiceForConditionalGenerationInference.from_pretrained("path/to/model")
model.to("cuda")

# 2. 准备输入
script = "Speaker 0: 你好，很高兴认识你！这是一段很长的话..."
voice_samples = ["path/to/voice.wav"]

inputs = processor(
    text=script,
    voice_samples=voice_samples,
    return_tensors="pt"
).to("cuda")

# 3. 创建 Streamer
batch_size = 1
streamer = AudioStreamer(batch_size=batch_size)

# 4. 播放线程
def play_stream():
    """实时播放线程"""
    print("开始播放...")
    for audio_chunk in streamer.get_stream(0):
        audio_numpy = audio_chunk.numpy()
        sd.play(audio_numpy, samplerate=24000)
        sd.wait()  # 等待播放完这一块
    print("播放结束")

play_thread = threading.Thread(target=play_stream)
play_thread.start()

# 5. 生成（主线程）
print("开始生成...")
with torch.no_grad():
    outputs = model.generate(
        **inputs,
        audio_streamer=streamer,  # 传入 streamer！
        cfg_scale=3.0,
        max_new_tokens=500
    )

# 6. 等待播放完成
play_thread.join()
print("全部完成！")
```

class VibeVoiceDemo:
    def generate_podcast_streaming(self, ...):
        # ... 初始化 ...
        
        def audio_generator():
            """生成器函数，用于 Gradio 流式输出"""

            # 启动生成线程
            def run_generation():
                with torch.no_grad():
                    outputs = self.model.generate(

        return audio_generator()

## 八、性能优化建议

### 8.1 缓冲区大小

```python
# 可以攒几帧再播放，减少播放开销
buffer_size = 3  # 3帧 = 400ms
audio_buffer = []

for audio_chunk in streamer.get_stream(0):
    audio_buffer.append(audio_chunk.numpy())
    if len(audio_buffer) &gt;= buffer_size:
        combined = np.concatenate(audio_buffer)
        sd.play(combined, 24000)
        sd.wait()
        audio_buffer = []

# 播放剩余
if audio_buffer:
    combined = np.concatenate(audio_buffer)
    sd.play(combined, 24000)
    sd.wait()
```

### 8.2 采样率转换

如果输出设备不支持 24kHz：

```python
import librosa

def resample_audio(audio, orig_sr=24000, target_sr=44100):
    return librosa.resample(audio, orig_sr=orig_sr, target_sr=target_sr)

for audio_chunk in streamer.get_stream(0):
    audio_numpy = audio_chunk.numpy()
    audio_resampled = resample_audio(audio_numpy, 24000, 44100)
    sd.play(audio_resampled, 44100)
    sd.wait()
```

### 8.3 延迟 vs 质量权衡

| 配置 | 延迟 | 质量 |
|-----|------|------|
| 20 步 + 每帧播放 | ~300ms | 高 |
| 10 步 + 每帧播放 | ~150ms | 中 |
| 20 步 + 3帧缓冲 | ~700ms | 高 + 流畅 |

## 九、总结

VibeVoice 流式音频输出的核心优势：

1. **基于队列的生产者-消费者模式**：解耦生成和播放
2. **支持批量**：可同时流式输出多个样本
3. **同步/异步双版本**：适配不同应用场景
4. **每帧 133ms**：提供接近实时的体验
5. **简单迭代器接口**：易于集成到各种应用

通过流式输出，VibeVoice 能够为用户提供流畅的实时语音合成体验。
