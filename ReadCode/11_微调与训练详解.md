
# 微调与训练详解

## 一、训练架构概览

VibeVoice 的训练系统设计支持高效的参数高效微调(PEFT),主要使用 LoRA 技术。系统分为几个关键组件:


### 冻结策略

```python

if model_args.freeze_acoustic_tokenizer:

        p.requires_grad = True
    for p in model.model.semantic_connector.parameters():
        p.requires_grad = True
```

## 四、损失函数

### 双重损失设计

VibeVoice 使用双重损失:

1. **交叉熵损失 (CE Loss)**: 优化文本生成
2. **扩散损失 (Diffusion Loss)**: 优化声学重建

```python
def compute_loss(self, model, inputs):
    # 1. 前向传播
    outputs = self.training_forward(model, inputs)
    
    # 2. CE Loss - 仅计算文本token损失
    logits = outputs.logits
    ce_labels = mask_for_ce(labels, attention_mask, acoustic_input_mask)
    shift_logits = logits[:, :-1, :].contiguous()
    loss_fct = nn.CrossEntropyLoss(ignore_index=-100)
    ce_loss = loss_fct(shift_logits.view(-1, shift_logits.size(-1)), 
                       ce_labels.view(-1))
    
    # 3. Diffusion Loss
    diffusion_loss = outputs.diffusion_loss
    
    # 4. 加权总损失
    total = training_args.ce_loss_weight * ce_loss + \
            training_args.diffusion_loss_weight * diffusion_loss
    
    return total
```

### 掩码函数 - mask_for_ce

确保只在文本 token 上计算 CE Loss,跳过语音占位符:

```python
def mask_for_ce(labels, attention_mask, acoustic_input_mask, pad_id=-100):
    shifted = labels[:, 1:].contiguous()
    base_mask = attention_mask[:, 1:].eq(1)
    label_is_acoustic = acoustic_input_mask[:, 1:]
    final_mask = base_mask &amp; (~label_is_acoustic)
    
    out = shifted.clone()
    out[~final_mask] = pad_id  # -100 会被忽略
    return out
```

## 五、扩散损失详解

### DDPM Batch Mul 技巧

通过重复特征多次采样时间步,提高训练效率:

```python
ddmp_batch_mul = training_args.ddpm_batch_mul  # 默认为1

# 重复特征
speech_features_repeated = speech_features.repeat_interleave(ddmp_batch_mul, dim=0)
condition_features_repeated = condition_features.repeat_interleave(ddmp_batch_mul, dim=0)

# 采样多个时间步
timesteps = torch.multinomial(
    torch.ones(model.config.diffusion_head_config.ddpm_num_steps),
    speech_len * ddmp_batch_mul,
    replacement=True,
)
```

### 噪声添加与预测

```python
# 添加噪声
noisy_speech_features = model.model.noise_scheduler.add_noise(
    speech_features_repeated, noise, timesteps
)

# 模型预测
model_output = model.model.prediction_head(
    noisy_speech_features, 
    timesteps.type_as(x), 
    condition_features_repeated
)

# 根据预测类型选择目标
prediction_type = model.config.diffusion_head_config.prediction_type
if prediction_type == "epsilon":
    target_for_loss = noise
elif prediction_type == "v_prediction":
    target_for_loss = model.model.noise_scheduler.get_velocity(
        speech_features_repeated, noise, timesteps
    )
```

### MSE Loss

```python
diffusion_loss = F.mse_loss(model_output.float(), target_for_loss.float(), reduction='sum')

# 归一化
diffusion_loss = diffusion_loss / latent_size / ddmp_batch_mul / max(speech_len, 1)
```

## 六、EMA (指数移动平均)

VibeVoice 使用 EMA 平滑扩散头参数,提高生成质量:

```python
class EmaCallback(TrainerCallback):
    def __init__(self, attr_path="model.prediction_head", decay=0.999, device="cpu"):
        self.attr_path = attr_path
        self.decay = decay
        self.device = device
        self.shadow = None
    
    def on_step_end(self, args, state, control, model=None, **kwargs):
        # 更新 EMA
        head = self._get_module(model)
        with torch.no_grad():
            for k, v in head.state_dict().items():
                self.shadow[k].mul_(self.decay).add_(
                    v.detach().to(self.device), 
                    alpha=(1.0 - self.decay)
                )
    
    def on_evaluate(self, args, state, control, model=None, **kwargs):
        # 评估时使用 EMA 权重
        self._swap_in_ema(model)
    
    def on_save(self, args, state, control, model=None, **kwargs):
        # 保存时使用 EMA 权重
        self._swap_in_ema(model)
```

## 八、训练超参数建议

### LoRA 参数

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| lora_r | 8-64 | LoRA 秩,越大越灵活但参数量越多 |
| lora_alpha | 16-64 | LoRA alpha,通常设为 r 的2倍 |
| lora_dropout | 0.05-0.1 | 防止过拟合 |
| lora_target_modules | q,k,v,o,gate,up,down | 全量注意力+FFN |

### 训练参数

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| learning_rate | 1e-4 - 5e-4 | LoRA 学习率 |
| batch_size | 4-16 | 取决于显存 |
| gradient_accumulation | 4-16 | 模拟更大 batch |
| num_train_epochs | 2-10 | 避免过拟合 |
| ce_loss_weight | 1.0 | CE 损失权重 |
| diffusion_loss_weight | 1.0 | 扩散损失权重 |
| ddpm_batch_mul | 1-4 | 重复采样,提高效率 |

## 十、调试与监控

### LoRA Debug Callback

监控 LoRA 参数更新情况:

```python
class LoRADebugCallback(TrainerCallback):
    def on_step_end(self, args, state, control, model=None, **kwargs):
        # 检查 LoRA 参数是否有更新
        changed_A = 0
        changed_B = 0
        for n in self.lora_param_names:
            p = dict(model.named_parameters())[n]
            prev = self.prev_param_norms[n]
            curr = float(p.data.norm().item())
            if "lora_A" in n and abs(curr - prev) &gt; eps:
                changed_A += 1
            if "lora_B" in n and abs(curr - prev) &gt; eps:
                changed_B += 1
        logger.info(f"LoRA debug: A changed {changed_A}, B changed {changed_B}")
```

## 十一、常见问题与解决方案

### 问题1: LoRA 参数不更新

**检查清单**:
- 确认 lora_target_modules 配置正确
- 检查 requires_grad 是否为 True
- 查看 LoRADebugCallback 输出

**解决方案**:
```python
# 确保目标模块名称正确
lora_target_modules = "q_proj,k_proj,v_proj,o_proj,gate_proj,up_proj,down_proj"
```

### 问题2: 显存不足

**解决方案**:
- 减小 batch_size
- 增加 gradient_accumulation_steps
- 启用 gradient_checkpointing
- 使用 LoRA 而非全量微调

### 问题3: 训练不稳定,损失发散

**解决方案**:
- 降低 learning_rate
- 启用 gradient_clipping
- 减小 ddpm_batch_mul
- 检查数据预处理是否正确

### 问题4: 生成质量下降

**解决方案**:
- 减少训练 epoch
- 增加 voice_prompt_drop_rate 作为正则化
- 使用更小的 LoRA rank
- 启用 EMA (默认已启用)
