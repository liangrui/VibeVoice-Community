
# 噪声调度器详解

## 一、概述

噪声调度器是扩散模型的核心组件，负责管理噪声添加和移除的整个过程。VibeVoice 使用了 DPM-Solver++ 多步求解器，在保持高质量的同时大幅减少推理步数。

## 三、噪声调度数学原理

### 3.1 Beta 调度 - 余弦策略

余弦调度相比线性调度在低信噪比区域（接近干净数据）更稳定：

```python
def betas_for_alpha_bar(num_diffusion_timesteps, alpha_transform_type="cosine"):
    def alpha_bar(t):
        if alpha_transform_type == "cosine":
            # 余弦调度
            return math.cos((t + 0.008) / 1.008 * math.pi / 2) ** 2
        ...
    
    betas = []
    for i in range(num_diffusion_timesteps):
        t1 = i / num_diffusion_timesteps
        t2 = (i + 1) / num_diffusion_timesteps
        betas.append(min(1 - alpha_bar(t2) / alpha_bar(t1), 0.999))
    
    return torch.tensor(betas, dtype=torch.float32)
```

### 3.2 Alpha 计算

```python
# 在 __init__ 中计算
self.alphas = 1.0 - self.betas
self.alphas_cumprod = torch.cumprod(self.alphas, dim=0)

# 计算 alpha_t 和 sigma_t (用于 v-prediction)
self.alpha_t = torch.sqrt(self.alphas_cumprod)
self.sigma_t = torch.sqrt(1 - self.alphas_cumprod)
```

### 3.3 前向扩散过程（添加噪声）

给定干净数据 $x_0$，任意时间步 $t$ 的噪声数据可直接计算：

$$
x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1 - \bar{\alpha}_t} \cdot \epsilon
$$

其中 $\bar{\alpha}_t = \prod_{i=1}^t \alpha_i$，$\epsilon \sim \mathcal{N}(0, I)$。

代码实现：

```python
def add_noise(
    self,
    original_samples: torch.Tensor,      # x_0
    noise: torch.Tensor,                 # ε
    timesteps: torch.IntTensor,          # t
) -&gt; torch.Tensor:
    # 获取对应时间步的 alpha_t 和 sigma_t
    alpha_t = self.alpha_t[timesteps].flatten()
    sigma_t = self.sigma_t[timesteps].flatten()
    
    # 扩展维度以匹配 original_samples
    while len(alpha_t.shape) &lt; len(original_samples.shape):
        alpha_t = alpha_t.unsqueeze(-1)
        sigma_t = sigma_t.unsqueeze(-1)
    
    # x_t = α_t * x_0 + σ_t * ε
    noisy_samples = alpha_t * original_samples + sigma_t * noise
    return noisy_samples
```

### 3.4 V-Prediction 预测类型

VibeVoice 使用 v-prediction 而非传统的 epsilon-prediction，v-prediction 定义为：

$$
v_t = \sqrt{\bar{\alpha}_t} \cdot \epsilon - \sqrt{1 - \bar{\alpha}_t} \cdot x_0
$$

这种预测类型对高信噪比区域（低噪声水平）更稳定。

计算 v-prediction 的方法：

```python
def get_velocity(
    self,
    sample: torch.Tensor,              # x_0
    noise: torch.Tensor,               # ε
    timesteps: torch.IntTensor         # t
) -&gt; torch.Tensor:
    alpha_t = self.alpha_t[timesteps]
    sigma_t = self.sigma_t[timesteps]
    
    # 扩展维度
    while len(alpha_t.shape) &lt; len(sample.shape):
        alpha_t = alpha_t.unsqueeze(-1)
        sigma_t = sigma_t.unsqueeze(-1)
    
    # v = α_t * ε - σ_t * x_0
    velocity = alpha_t * noise - sigma_t * sample
    return velocity
```

## 四、时间步采样器

在 [`vibevoice/schedule/timestep_sampler.py`](file:///workspace/vibevoice/schedule/timestep_sampler.py) 中定义了两种采样策略。

### 4.1 均匀采样器

```python
class UniformSampler:
    def __init__(self, timesteps=1000):
        self.timesteps = timesteps
    
    def sample(self, batch_size, device):
        # 从 [0, 1000) 均匀随机采样
        return torch.randint(0, self.timesteps, (batch_size,), device=device)
```

### 4.2 Logit-Normal 采样器

对中间时间步给予更高的权重：

```python
class LogitNormalSampler:
    def __init__(self, timesteps=1000, m=0, s=1):
        self.timesteps = timesteps
        
        # 计算 logit-normal 概率分布
        timesteps_normalized = torch.linspace(0, 1, timesteps)
        logit = torch.log(timesteps_normalized / (1 - timesteps_normalized))
        
        # 正态分布概率密度函数
        self.prob = torch.exp(-0.5 * (logit - m) ** 2 / s ** 2) / (s * math.sqrt(2 * math.pi))
    
    def sample(self, batch_size, device):
        # 根据概率分布采样
        return torch.multinomial(self.prob, batch_size, replacement=True).to(device)
```

## 五、DPM-Solver++ 推理采样

### 5.1 设置时间步

首先需要为推理设置离散时间步：

```python
def set_timesteps(
    self,
    num_inference_steps: int = None,  # 推理步数，如 20
    device: Union[str, torch.device] = None,
    timesteps: Optional[List[int]] = None,
):
    # linspace 间隔：从 0 到 last_timestep 线性间隔
    if self.config.timestep_spacing == "linspace":
        timesteps = (
            np.linspace(0, last_timestep - 1, num_inference_steps + 1)
            .round()[::-1][:-1]
            .copy()
            .astype(np.int64)
        )
    
    # 计算 sigmas (用于 DPM-Solver)
    sigmas = np.array(((1 - self.alphas_cumprod) / self.alphas_cumprod) ** 0.5)
    
    self.timesteps = torch.from_numpy(timesteps).to(device=device)
    self.sigmas = torch.from_numpy(sigmas).to(device=device)
    
    # 初始化模型输出缓存（用于多步求解器）
    self.model_outputs = [None] * self.config.solver_order
```

### 5.2 一阶更新（DPM-Solver 1 阶）

```python
def dpm_solver_first_order_update(
    self,
    model_output: torch.Tensor,
    sample: torch.Tensor = None,
    ...
) -&gt; torch.Tensor:
    # 获取当前和前一个时间步的 sigma
    sigma_t, sigma_s = self.sigmas[self.step_index + 1], self.sigmas[self.step_index]
    
    # 转换为 alpha 和 sigma
    alpha_t, sigma_t = self._sigma_to_alpha_sigma_t(sigma_t)
    alpha_s, sigma_s = self._sigma_to_alpha_sigma_t(sigma_s)
    
    # 计算 lambda = log(alpha) - log(sigma)
    lambda_t = torch.log(alpha_t) - torch.log(sigma_t)
    lambda_s = torch.log(alpha_s) - torch.log(sigma_s)
    
    h = lambda_t - lambda_s  # 步长
    
    # DPM-Solver++ 更新公式
    if self.config.algorithm_type == "dpmsolver++":
        x_t = (sigma_t / sigma_s) * sample - (alpha_t * (torch.exp(-h) - 1.0)) * model_output
    ...
    
    return x_t
```

### 5.3 二阶更新（DPM-Solver 2 阶）

```python
def multistep_dpm_solver_second_order_update(
    self,
    model_output_list: List[torch.Tensor],  # 最近两个模型输出
    sample: torch.Tensor = None,
    ...
) -&gt; torch.Tensor:
    # 获取三个时间点的 sigma
    sigma_t, sigma_s0, sigma_s1 = (
        self.sigmas[self.step_index + 1],
        self.sigmas[self.step_index],
        self.sigmas[self.step_index - 1],
    )
    
    alpha_t, sigma_t = self._sigma_to_alpha_sigma_t(sigma_t)
    alpha_s0, sigma_s0 = self._sigma_to_alpha_sigma_t(sigma_s0)
    alpha_s1, sigma_s1 = self._sigma_to_alpha_sigma_t(sigma_s1)
    
    lambda_t = torch.log(alpha_t) - torch.log(sigma_t)
    lambda_s0 = torch.log(alpha_s0) - torch.log(sigma_s0)
    lambda_s1 = torch.log(alpha_s1) - torch.log(sigma_s1)
    
    m0, m1 = model_output_list[-1], model_output_list[-2]
    
    h, h_0 = lambda_t - lambda_s0, lambda_s0 - lambda_s1
    r0 = h_0 / h
    
    # 线性外推
    D0, D1 = m0, (1.0 / r0) * (m0 - m1)
    
    if self.config.algorithm_type == "dpmsolver++":
        x_t = (
            (sigma_t / sigma_s0) * sample
            - (alpha_t * (torch.exp(-h) - 1.0)) * D0
            - 0.5 * (alpha_t * (torch.exp(-h) - 1.0)) * D1
        )
    
    return x_t
```

### 5.4 三阶更新（DPM-Solver 3 阶）

```python
def multistep_dpm_solver_third_order_update(
    self,
    model_output_list: List[torch.Tensor],  # 最近三个模型输出
    sample: torch.Tensor = None,
    ...
) -&gt; torch.Tensor:
    sigma_t, sigma_s0, sigma_s1, sigma_s2 = (
        self.sigmas[self.step_index + 1],
        self.sigmas[self.step_index],
        self.sigmas[self.step_index - 1],
        self.sigmas[self.step_index - 2],
    )
    
    ...
    
    m0, m1, m2 = model_output_list[-1], model_output_list[-2], model_output_list[-3]
    
    h, h_0, h_1 = lambda_t - lambda_s0, lambda_s0 - lambda_s1, lambda_s1 - lambda_s2
    r0, r1 = h_0 / h, h_1 / h
    
    # 二次外推
    D0 = m0
    D1_0 = (1.0 / r0) * (m0 - m1)
    D1_1 = (1.0 / r1) * (m1 - m2)
    D1 = D1_0 + (r0 / (r0 + r1)) * (D1_0 - D1_1)
    D2 = (1.0 / (r0 + r1)) * (D1_0 - D1_1)
    
    if self.config.algorithm_type == "dpmsolver++":
        x_t = (
            (sigma_t / sigma_s0) * sample
            - (alpha_t * (torch.exp(-h) - 1.0)) * D0
            + (alpha_t * ((torch.exp(-h) - 1.0) / h + 1.0)) * D1
            - (alpha_t * ((torch.exp(-h) - 1.0 + h) / h ** 2 - 0.5)) * D2
        )
    
    return x_t
```

### 5.5 主 Step 函数

```python
def step(
    self,
    model_output: torch.Tensor,  # 模型预测输出
    timestep: int,               # 当前时间步
    sample: torch.Tensor,        # 当前样本 x_t
    ...
) -&gt; Union[SchedulerOutput, Tuple]:
    # 1. 初始化 step_index
    if self.step_index is None:
        self._init_step_index(timestep)
    
    # 2. 根据步数决定使用的阶数
    lower_order_final = (
        (self.step_index == len(self.timesteps) - 1) 
        and (self.config.euler_at_final or (self.config.lower_order_final and len(self.timesteps) &lt; 15))
    )
    lower_order_second = (
        (self.step_index == len(self.timesteps) - 2) 
        and self.config.lower_order_final 
        and len(self.timesteps) &lt; 15
    )
    
    # 3. 转换模型输出（如从 v_pred 转 epsilon）
    model_output = self.convert_model_output(model_output, sample=sample)
    
    # 4. 滚动保存模型输出（用于多步）
    for i in range(self.config.solver_order - 1):
        self.model_outputs[i] = self.model_outputs[i + 1]
    self.model_outputs[-1] = model_output
    
    # 5. 选择合适的求解器阶数
    if self.config.solver_order == 1 or self.step_index &lt; 1 or lower_order_final:
        prev_sample = self.dpm_solver_first_order_update(
            model_output, sample=sample, ...
        )
    elif self.config.solver_order == 2 or self.step_index &lt; 2 or lower_order_second:
        prev_sample = self.multistep_dpm_solver_second_order_update(
            self.model_outputs, sample=sample, ...
        )
    else:
        prev_sample = self.multistep_dpm_solver_third_order_update(
            self.model_outputs, sample=sample, ...
        )
    
    # 6. 更新 step_index
    self.step_index += 1
    
    return SchedulerOutput(prev_sample=prev_sample)
```

### 6.2 在 VibeVoice 推理中的使用

```python
@torch.no_grad()
def sample_speech_tokens(self, condition, neg_condition, cfg_scale=3.0):
    # 1. 设置推理步数
    self.noise_scheduler.set_timesteps(self.ddpm_inference_steps)
    
    # 2. 拼接正负条件（用于 CFG）
    condition = torch.cat([condition, neg_condition], dim=0)
    
    # 3. 初始化随机噪声
    speech = torch.randn(condition.shape[0], self.config.acoustic_vae_dim).to(condition)
    
    # 4. 去噪循环
    for t in self.noise_scheduler.timesteps:
        # 当前样本对半复制（正负条件各一份）
        half = speech[: len(speech) // 2]
        combined = torch.cat([half, half], dim=0)
        
        # 模型预测
        eps = self.model.prediction_head(
            combined, 
            t.repeat(combined.shape[0]), 
            condition=condition
        )
        
        # CFG 引导
        cond_eps, uncond_eps = torch.split(eps, len(eps) // 2, dim=0)
        half_eps = uncond_eps + cfg_scale * (cond_eps - uncond_eps)
        eps = torch.cat([half_eps, half_eps], dim=0)
        
        # 调度器一步去噪
        speech = self.noise_scheduler.step(eps, t, speech).prev_sample
    
    return speech[: len(speech) // 2]  # 只返回正条件的结果
```

## 七、关键参数选择

### 7.1 推理步数 vs 质量

| 推理步数 | 质量 | 速度 | 适用场景 |
|---------|------|------|---------|
| 10 | 一般 | 很快 | 实时流式 |
| 20 | 好 | 快 | 平衡选择 |
| 50 | 很好 | 中等 | 高质量生成 |
| 100 | 最佳 | 慢 | 离线批量 |

VibeVoice 默认使用 20 步，在质量和速度间取得良好平衡。

### 7.2 求解器阶数

| 阶数 | 精度 | 缓存 | VibeVoice 使用 |
|-----|------|------|----------------|
| 1 | 低 | 无 | 早期阶段 |
| 2 | 中 | 1个历史 | 主要阶段 |
| 3 | 高 | 2个历史 | 可选提升 |

### 7.3 Beta 调度对比

| 调度类型 | 特点 | VibeVoice |
|---------|------|-----------|
| linear | 简单通用 | - |
| cosine | 低 SNR 更稳定 | ✓ |
| scaled_linear | 潜在空间优化 | - |

generated_audio = sample

## 九、总结

VibeVoice 噪声调度器的核心特点：

1. **DPM-Solver++ 多步求解器**：大幅减少推理步数（1000→20）
2. **余弦 Beta 调度**：在低 SNR 区域更稳定
3. **V-Prediction**：对语音生成任务更适合
4. **二阶为主**：在精度和效率间平衡
5. **CFG 兼容**：支持无分类器引导提升质量
